# Проверка Telegram-интеграции — 3 ноября 2026

**39 тестов бота прошли**, Ruff прошёл. Интеграционный smoke настоящего
`BackendClient` и backend с детерминированной моделью прошёл отдельно, без сети
и вызова sender. [Запись результатов тестов](2026-11-03/test-results.json).

Реальные backend, Ollama и HTTP API бота прошли readiness, RAG с источником и
девять ходов на одном persistent thread: сохранение метки, два свежих вызова
времени, поиск с точной цитатой, восстановление метки, preview, cancel,
новое preview и проверка забытой метки после полной очистки. Устаревший request ID
отклонён с 409. Медиана хода — 0.833 с; 14 модельных вызовов, 14 568 токенов.

Polling, broadcasts и положительный resume не запускались. Использован настоящий
API бота с синтетическим токеном; источники backend смонтированы read-only,
образы в этом прогоне не пересобирались. Это проверка preview/cancel и очистки,
а не доказательство реальной доставки в Telegram. Ресурсы измерены на всём хосте,
включая другие процессы.
